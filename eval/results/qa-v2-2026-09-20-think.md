Answers the judge marked unsupported:

- `m01` (answerable): Upgrading a Cannon Tower to level 2 costs 180 gold. The base cost is 120 gold [2]. The upgrade cost formula is 0.75 times the base cost times N (where N is the target level) [1], or calculated as int(base_cost * 0.75 * (level + 1)) in code [3]. For level 2, the calculation is 120 * 0.75 * 2 = 180.
- `m03` (answerable): The total gold needed is 260 gold. This consists of the base Frost Tower cost of 80 gold [1] plus upgrade costs calculated as 0.75 × base cost × level N [2]. For level 3: 0.75 × 80 × 3 = 180 gold in upgrades, totaling 80 + 180 = 260 gold.
- `m10` (answerable): Waves 1 through 3 pay out a total of 435 gold. Wave 1 pays 135 (100 base + 10 wave number + 25 flawless), Wave 2 pays 145 (100 base + 20 wave number + 25 flawless), and Wave 3 pays 155 (100 base + 30 wave number + 25 flawless).
- `h01` (answerable): The Brute is worth the most loot at 25 gold bounty. The Grunt pays only 5 gold bounty. The Shardlord boss does not have a bounty value specified in the provided sources.
- `h05` (answerable): The file data/waves.json contains information about how many monsters come in each round. Source [1] shows the waves array with enemy counts per wave.

## Caveats

- 36 answerable + 14 unanswerable questions over a small synthetic corpus written by the project author; treat small differences as noise.
- Correctness is a keyword check (required facts present), not a judgement of prose.
- Faithfulness is judged by the same local model that answers; see the judge validation.
- Generation uses temperature 0, but local inference is not guaranteed bit-identical.
